Backend Integration

This page talks to the FastAPI engine in main.py.

1. Start the engine 
pip install fastapi uvicorn numpy scikit-learn
python main.py     # serves http://127.0.0.1:5000
2. Endpoints used by this page 
GET  /                          → health check (header pill)
POST /api/enroll                → 7 baseline trials (Supervised RF Classifier)
POST /api/verify                → live authentication (Probabilistic verification)
POST /api/bioprint/telemetry    → mode taken from session.mode
3. Payload contract (must match main.py) 
{
  "subject":    { "username": "alex.cyber", "password": "••••••••" },
  "session":    { "mode": "enroll" | "verify" },
  "signals":    { "flags": ["robotic_key_interval", ...] },
  "keystrokes": { "password": { "derived": {
      "dwell": { "mean": 95.2, "sd": 21.8 },
      "ud":    { "mean": 140.4, "sd": 34.9 },
      "typingSpeedCps": 3.8 } } },
  "pointer":    { "derived": {
      "speedPxPerMs": { "mean": 0.45 },
      "straightness": { "mean": 0.70 },
      "turnAngleRad": { "sd": 0.85 } } }
}
